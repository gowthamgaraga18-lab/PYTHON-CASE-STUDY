🧠 Key Concepts Covered
Control Flow & Conditionals: if-elif-else branching, ternary expressions, and input validation.
Iteration: for and while loops for sequential processing and threshold convergence.
Data Structures: Lists, 2D matrices (nested lists), tuples, and tuple unpacking.
Built-in Functions & Formatting: min(), max(), sum(), len(), and formatted string literals (f-strings) for tabular reports and currency formatting.

⚙️ Prerequisites & Setup
Python Version: Python 3.6 or higher (required for f-string formatting).
Dependencies: None (uses only standard Python built-in libraries).
Recommended Environments: Local terminal/IDLE, VS Code, or online compilers such as OneCompiler.

▶️ Running the Programs
Save the Code: Copy the Python code from any desired case study into a .py file (e.g., case_study_1.py).
Execute via Terminal:
python case_study_1.py
Provide Inputs:
For Case Studies 1–5, follow the on-screen prompts to enter test values via standard input (STDIN).
For Case Studies 6–10, sample datasets are hardcoded inside the scripts and will output the formatted reports immediately upon execution.
